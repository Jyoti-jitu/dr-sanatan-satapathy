# Dr. Sanatan Satapathy – Premium Neurosurgery & Spine Website

Official website for **Dr. Sanatan Satapathy**, Senior Neurosurgeon & Spine Surgeon in Bhubaneswar, Odisha, India.

Built with **Next.js (App Router)**, **React**, and **Tailwind CSS**. Designed with an international healthcare editorial aesthetic, comprehensive clinical architecture, accessible typography, Schema.org medical structured data, and authentic practitioner photography.

---

## 🩺 Clinical Positioning & Specialities
* **Brain Surgery & Microneurosurgery:** Tumour excisions, neurotrauma, intracranial hematomas, skull base approaches.
* **Spine Surgery & Decompression:** Cervical, thoracic, and lumbar degenerative disc disease, canal stenosis, and stabilization.
* **Endoscopic Spine Surgery:** Ultra-minimally invasive disc removal through sub-centimeter portals (&lt; 8 mm).
* **Minimally Invasive Spine Surgery (MISS):** Muscle-sparing tubular access and percutaneous instrumentation.

## 🚀 Technical Features
* **Next.js 14 App Router** with full Static Site Generation (SSG) and Server-Side Rendering (SSR).
* **Complete Website Architecture:**
  * `/` (14-section comprehensive editorial homepage)
  * `/about` (Doctor profile, surgical philosophy, and academic journey)
  * `/brain-surgery` (Cranial microsurgery and neurotrauma protocols)
  * `/spine-surgery` (Conservative care first, spine stabilization)
  * `/endoscopic-spine-surgery` (Sub-centimeter keyhole procedures)
  * `/minimally-invasive-spine-surgery` (Tubular MISS approaches)
  * `/conditions` (Patient condition directory)
  * `/conditions/[slug]` (7 dedicated condition guides: brain-tumour, slipped-disc, spinal-stenosis, cervical-disc, lumbar-disc, head-injury, nerve-compression)
  * `/achievements` (Times Health ICON 2024, AIIMS fellowship, society memberships)
  * `/hospitals` (Consultation centers, OPD timings, Google Maps directions)
  * `/contact` (Interactive consultation booking form with validation and instant WhatsApp integration)
  * `/privacy-policy` & `/disclaimer` (Emergency triage alert and NMC compliance)
* **SEO & Structured Data:** Semantic HTML5, OpenGraph tags, dynamic `/sitemap.xml`, `/robots.txt`, and Schema.org `Physician` & `MedicalCondition` JSON-LD.
* **Brand Identity:** Palette of Deep Navy (`#10263D`), Primary Navy (`#17324D`), Medical Teal (`#188B8E`), Light Teal (`#EAF5F4`), and Accent Gold (`#B99A65`).

## 🛠️ Local Development

```bash
# Install dependencies
npm install

# Start development server
npm run dev

# Create production build
npm run build

# Run production server
npm run start
```
The site will be accessible at [http://localhost:3000](http://localhost:3000).
